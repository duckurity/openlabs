DESCRIPTION
==================================================

The Midea MSCT-12CR is a 1.5 horsepower split air
conditioner designed for cooling residential spaces.

The unit provides a cooling capacity of 12000 BTU and
uses a conventional cooling-only system. It includes
Midea's Green Plasma Ion technology, designed to help
improve air quality inside the room.

The air conditioner features a Turbo Cool function for
faster cooling when the room needs to reach the desired
temperature quickly. It also includes an ECO mode designed
to help reduce energy consumption during operation.

The MSCT-12CR includes a high-tech LCD display and a
built-in timer, allowing users to monitor and control
the operating settings more conveniently.

The unit also features an anti-dust filter and is designed
as a split system with separate indoor and outdoor units.

Main Specifications:
- Brand: Midea
- Model: MSCT-12CR
- Type: Split Air Conditioner
- Cooling Type: Cooling Only
- Horsepower: 1.5 HP
- Cooling Capacity: 12000 BTU
- Turbo Function: Yes
- ECO Mode: Yes
- Green Plasma Ion Technology: Yes
- LCD Display: Yes
- Built-In Timer: Yes
- Filter: Anti-Dust Filter
- Color: White
- Indoor Unit Dimensions: 192 x 300 mm
- Installation Type: Split System
