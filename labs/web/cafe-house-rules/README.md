# cafe-house-rules

`medium` · `web`

## Brief

Quack and Grind Cafe publishes house rules for guests. Staff can review cafe links through an internal browser. Find the back-room route and read the flag.

## Setup

Run these from the lab directory:

```bash
docker compose up -d
```

Open `http://localhost:8388`.

## Goal

Find the flag. Verify the solve from the lab directory:

```bash
python3 ../../../scripts/check.py .
```

See [how to play](/play) for the usual solve loop.
