Backstage Archive API

Internal API for searching the Backstage merchandise archive. Authenticate with your issued account, then use your session token on subsequent requests.

Endpoints

MethodPathAuthPurpose
POST/api/loginNoExchange credentials for a session token
GET/api/meYesShow basic account information
GET/api/productsYesList public products
GET/api/search?q=...YesSearch products by name
POST/api/logoutYesInvalidate the current session token
GET/healthNoService health check

Login

POST /api/login
Content-Type: application/json

{
  "username": "researcher",
  "password": "<provided-lab-password>"
}

Authenticated requests

Include the token returned from login on every other request:

Authorization: Bearer <session-token>

Search example

GET /api/search?q=Hoodie
Authorization: Bearer <session-token>
