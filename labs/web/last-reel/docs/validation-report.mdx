## Validation coverage

The 32 tests cover:

- public catalogue and detail behavior;
- the intended SQL injection;
- input limits and error redaction;
- headers, health, and non-public paths;
- SQLite authorizer and resource limits;
- seed and digest behavior, operator metadata updates, and reset error reporting when cleanup also fails;
- evaluator URL validation and solver parsing of real rendered output;
- frontend navigation, copy, accessible names, interaction styles, contrast tokens, and reduced motion.

| Scope | Coverage limit |
|---|---|
| Application tests | Bounded evidence for the intended path and selected negative cases; not proof against every unintended behavior |
| Runtime isolation | Checked controls on one Docker Desktop host; not proof of kernel or Docker Engine isolation |
| Accessibility | Sampled contrast: placeholder `5.50:1`, focus `5.07:1`, input boundary `3.46:1`. Not a full WCAG review; no screen-reader or cross-browser pass |
| Supply chain | Base image pinned by digest and wheels pinned by hash; no image vulnerability scan is recorded in this report |
| Timings | One host; build time depends on network speed and local base-image layers |

## Reproduction

From the repository root:

```text
python3 scripts/validate.py --compose
python3 scripts/score_lab.py labs/web/last-reel --min 100
python3 scripts/make_lab_pdf.py labs/web/last-reel --strict
```

From the lab directory:

```text
docker compose build --no-cache
docker build --target test -t last-reel:test .
docker run --rm --network none --read-only --user 10001:10001 --cap-drop ALL --security-opt no-new-privileges --tmpfs /tmp:rw,noexec,nosuid,nodev,size=16m,uid=10001,gid=10001,mode=0700 last-reel:test
docker compose up -d --wait
python3 scripts/sync_flag_hash.py
python3 solver/solve.py --base-url http://127.0.0.1:8080
python3 ../../../scripts/check.py .
python3 reset.py
docker compose down
```

The first build needs internet access for the pinned base image and Python wheels. Startup, reset, and play need no network. The solver prints the current runtime flag; run it only in a private evaluator terminal and do not save its output. The manual path is in the [official solution](official-solution.mdx).
