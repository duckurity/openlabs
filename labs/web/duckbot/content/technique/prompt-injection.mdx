## Overview

Prompt injection occurs when crafted input manipulates an AI application into ignoring or overriding its intended instructions. Depending on the application's design, this may cause it to disclose internal instructions or expose information that should remain confidential.

## FAQ

### Does prompt injection always expose the system prompt?

No. The impact depends on how the application processes user input and handles sensitive information. Prompt injection may influence application behavior, but system prompt disclosure is only one possible outcome.
