# duck-nest

`medium` · `web`

## Brief

The nest is the conservation office's internal project workspace. Staff and interns log in with workspace accounts and keep project documents inside. One project stays restricted. Read its documents.

Sign in with `intern` and `marshroad`.

## Setup

Run these from the lab directory:

```bash
docker compose up -d
```

Open `http://localhost:8378`.

## Goal

Extract the flag from the restricted project. Verify the solve from the lab directory:

```bash
python3 ../../../scripts/check.py .
```

See [how to play](/play) for the usual solve loop.
