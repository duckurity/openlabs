## Do labs need an account?

No. No accounts exist. No scoring server exists. Verify each solve locally.

## Can I read the source to find the flag?

Yes. Reading the lab source counts as a solve. Open labs work that way.

## What do I need to run a lab?

Install Docker with Compose v2. Install `python3` for the flag checker. Clone the repo. Enter a lab. Run `docker compose up -d`. Open the host port.

## Do labs run offline?

Yes. Pull the images first. Labs run offline after the pull. Nothing leaves your machine.

## Where do I start?

Start with an `easy` lab. Read [how to play](/play) for the loop. Browse the [labs](/labs) to pick a target.

## A lab looks broken. What now?

Report it through the issue forms. Name the lab, the track, and the step that fails. Never report the lab vulnerabilities. They form the product.
