## Overview

A hardcoded secret is a value the app needs to check something, such as a PIN, password, API key, or promo code, written straight into its code or resources. The app ships to every user, so every user also receives the secret. Client-side checks only hide it from people who never look.

## Examples

Unpack the app and read what it contains. Decompile the code and search it for strings, constants, and comparisons that look like credentials. Check resource files and build settings too, since values often live there instead of in the code.

## FAQ

**Is a secret safe if the app is obfuscated?**

No. Obfuscation only slows a reader down. If the app can use the value, someone with the app can recover it.

**Do I need special tooling?**

A decompiler such as JADX is enough for an Android app. Read [how to play](/play) for the loop.
