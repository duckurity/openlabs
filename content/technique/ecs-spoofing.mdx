## Overview

EDNS Client Subnet (RFC 7871) lets a resolver's client declare which network
it is querying from, so the resolver can return geographically relevant
answers. The field is just part of the query the client sends — nothing
authenticates it. A server that uses it to decide whether a zone is
"internal-only" is trusting data the client wrote itself.

## Examples

Look for a DNS service that refuses a plain query but behaves differently
once an EDNS Client Subnet option is attached (for example with
`dig +subnet=<cidr>`). A `REFUSED` baseline followed by a successful answer
once a specific subnet is declared is the tell.

## FAQ

**Is this the same as IP spoofing?**

No. Real IP spoofing forges the packet's source address and usually can't
complete a UDP round trip back to the attacker. ECS spoofing forges a field
*inside* a normal, correctly-addressed query — the response comes straight
back, no packet-level tricks needed.

**Do I need special tooling?**

No. `dig` and `nmap` are enough. Read [how to play](/play) for the loop.
