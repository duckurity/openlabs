## Overview

DNS is the phonebook of the Internet. It translates domain names to IP addresses. Attackers abuse it for command and control or data exfiltration because DNS traffic is frequently allowed through firewalls.

See the [dns-exfil](/labs/dns-exfil) lab, where a compromised host leaks data through DNS queries.

## FAQ

### Why do attackers use DNS for exfiltration?

DNS traffic is rarely blocked, so data hidden in query names can leave a network even when other outbound traffic is filtered.

### How can defenders spot it?

Look for unusually long or high-entropy subdomains, many queries to a single unfamiliar domain, and regular query patterns that do not match normal browsing.
