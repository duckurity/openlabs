## Overview

SQL injection occurs when untrusted input is incorporated into a database query without appropriate parameterization or validation. Player-controlled input can alter the intended SQL query and may expose records beyond the application's normal search behavior.

## FAQ

### Is every SQL error a SQL injection?

No. An error may only mean the query failed. Injection requires proof that attacker-controlled input changed query behavior.
