## Overview

Broken object-level authorization means the server verifies your session but never checks that the requested object belongs to you. Swap one identifier for another and the server hands over someone else's data with a `200 OK`.

## Examples

Watch for identifiers in URLs, request bodies, and API paths: `/api/reports/1`, `?user_id=42`, `{"document_id": 7}`. Change the value. Compare the response. A different user's object in the response confirms the flaw.

## FAQ

**Is IDOR the same as broken access control?**

IDOR is one shape of it. The family covers missing function-level checks too. This page covers the object-level shape only.

**Do I need special tooling?**

No. A browser and a willingness to edit one number suffice. Read [how to play](/play) for the loop.
