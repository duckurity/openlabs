Run each lab offline. Pull the images first. Nothing leaves your machine.

Ship one documented host port per lab. Keep the container port fixed.

Keep plaintext flags inside lab internals. The repo stores the SHA-256 hash in `lab.yml`. Flags follow `duck{...}`. Use lowercase letters, digits, and underscores between the braces. Keep the length between `16` and `40` characters. Match `^duck\{[a-z0-9_]{16,40}\}$`.

Publish writeups on your own site. Link the lab. Written content stays under CC-BY-4.0. Code stays under Apache-2.0.

The lab vulnerabilities need no report. They form the product. Report lab infrastructure issues through GitHub Private Vulnerability Reporting.
