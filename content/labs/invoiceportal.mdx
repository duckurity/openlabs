## Brief

Northwind Traders uses InvoicePortal. One invoice has a hidden flag.

Find it.

## Setup

Run these from the lab directory:

```bash
docker compose up -d
```

The application will be available at: http://localhost:5000/

## Reset

```
docker compose down -v && docker compose up -d
```
